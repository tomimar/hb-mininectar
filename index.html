Introduction

Mini Nectar

Hummingbird's design system for prototypes and experiments. It stays close enough to Nectar that a prototype looks like the real product, and loose enough to try what Nectar doesn't have yet.

What it's for

web

Prototype a screen or a flow

Build a screen or a flow with real components to review it, test it with users or explain it to the team.

science

Try a component before Nectar has it

Build it in a prototype and check it with real content. If it works, it moves into the system.

integration_instructions

Guide development

Each component has a guide with its structure, states, behaviour and accessibility rules, to use as a reference for the spec.

auto_awesome

Prototype with Claude

Claude Code reads the same guides, and in Claude Design the Mini Nectar artifact lets you design with the system's components and rules directly.

What you get

  • paletteNectar's look. The same tokens, type and components, in light and dark mode.
  • boltWorking components. Menus, modals, tables and reorderable lists work from their markup, through hb.js.
  • accessibility_newAccessibility built in. Visible focus, keyboard support and an alternative to every drag.
  • syncOne source. A change made here reaches these docs, Claude Code and the Claude Design artifact.
  • inventory_2Stable prototypes. Each prototype stays on the version it was created with, and can be shared as a zip that works offline.

How it works

  1. 1

    Start it

    Ask Claude for a prototype, or run one command. You get a folder from a template, pinned to the latest version.

  2. 2

    Build it

    Copy each component's example from these docs and fill it with real content.

  3. 3

    Share it

    Send the zip. It opens in any browser by double-click, no server needed.

Mini Nectar and Nectar

Mini Nectar is for prototyping and trying ideas — it isn't production code. When an idea becomes a feature, it is built with Nectar, using the prototype and the component's guide as the spec.

Get started

With Claude Code

Open this repo in Claude Code and ask for it:

"Create a prototype called alert-review with the case-tab template."

Or run it yourself, from the repo:

python3 scripts/new_prototype.py ~/Documents/Prototypes/alert-review --template case-tab --zip

--template blank or case-tab · --zip to share · --offline to open with no internet · --version to pin another release.

With Claude Design

Pick the Mini Nectar design system and describe the screen you want. The artifact takes care of everything: it carries the same tokens, guidelines, components and behaviour as this repo, so there's nothing to install or link.

By hand

Each thing is written once, in this repo. Everything else is generated from it.

After a change, the sync-artifact skill copies it to Claude Design. To add a component, use the add-component skill.

A prototype stays on the version it was created with. When a set of changes is ready for new prototypes, publish a release:

python3 scripts/release.py 1.1.0 "What changed, in one line"

MAJOR when a change can break an existing prototype, MINOR for anything new, PATCH for fixes. Every release is in the changelog.
