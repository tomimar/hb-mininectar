Mini Nectar Design System

A mini version of Nectar
for prototyping

hb-mininectar is a lightweight CSS design system built on top of Hummingbird's Nectar DS tokens. It gives Claude Code everything it needs to build consistent, on-brand HTML prototypes.

Read the docs

Installation

Add two lines to the <head> of any HTML prototype. No build step, no dependencies.

<link rel="stylesheet" href="https://tomimar.github.io/hb-mininectar/tokens.css">
<link rel="stylesheet" href="https://tomimar.github.io/hb-mininectar/components.css">

Using with Claude Code

Clone this repo and open it with Claude Code. The CLAUDE.md file gives Claude everything it needs to build a new prototype from scratch.

git clone https://github.com/tomimar/hb-mininectar

Then tell Claude Code what to build:

"Create a new HTML prototype in a folder called [name]. Use the hb-mininectar design system."
