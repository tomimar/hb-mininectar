Mini Nectar

A mini version of Nectar for prototyping

Hummingbird's design system for prototypes and experiments: tokens, components and their behaviour, close enough to Nectar that a prototype reads as the real thing. One source in this repo feeds these docs, Claude Code and Claude Design.

Start a prototype

With Claude Code

Open this repo in Claude Code and ask for it — the new-prototype skill does the rest:

"Create a prototype called alert-review with the case-tab template."

Or run it yourself, from the repo:

python3 scripts/new_prototype.py ~/Documents/Prototypes/alert-review --template case-tab
OptionWhat it does
--template blank · case-tabAn empty page, or a tab inside a Hummingbird case.
--zipAlso writes a zip, ready to share.
--offlinePuts everything it loads inside the folder (Mini Nectar, fonts, Tailwind, Alpine), so it opens with no internet.
--version v1.0.0Pins another release. By default, the latest.

With Claude Design

Pick the Mini Nectar design system. It carries the same tokens, guidelines, component guides, styles and behaviour as this repo.

By hand

Load Mini Nectar pinned to a release, so later changes never touch a prototype you've shared:

<!-- <head> -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tomimar/hb-mininectar@{version}/tokens.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/tomimar/hb-mininectar@{version}/components.css">
<script src="https://cdn.tailwindcss.com"></script>   <!-- layout only -->

<!-- end of <body> -->
<script src="https://cdn.jsdelivr.net/gh/tomimar/hb-mininectar@{version}/hb.js"></script>
<script src="https://cdn.jsdelivr.net/gh/tomimar/hb-mininectar@{version}/datepicker.js"></script>

hb.js makes components work from their markup — open, close, menus, reorder. Alpine.js is optional, only for a prototype's own logic. Copy any component's markup from its page here.

Where things live

Each thing is written once, in this repo. Everything else is generated from it.

WhatWritten inShows up in
Tokenstokens.jsontokens.css (via scripts/build_tokens.py), the Foundations pages, Claude Design
Design rulesguidelines.mdThe Foundations pages, Claude Design's README
Component guide and examplescomponents/<name>.mdEach component page, Claude Design
Component stylescomponents.cssEvery prototype, Claude Design (bundle.css)
Component behaviourhb.js, datepicker.jsEvery prototype, Claude Design (bundle.js)

After a change, the sync-artifact skill copies it to Claude Design. To add a component, use the add-component skill.

Versions

Latest release: {version}. A prototype stays on the release it was created with. When a set of changes is ready for new prototypes, publish a release:

python3 scripts/release.py 1.1.0 "What changed, in one line"

MAJOR when a change can break an existing prototype, MINOR for anything new, PATCH for fixes. Every release is in the changelog.
