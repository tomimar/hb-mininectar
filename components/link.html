Components

Link

Links let users navigate to related content or trigger lightweight actions. They provide a low-emphasis way to move across the product without competing with primary actions.

Example

Use hb-link on an anchor. It is underlined by default and removes the underline on hover/focus.

Types

Three variants for different contexts. Start with Default; use Subtle when the link competes with more important content, and Reverse only on dark or colored backgrounds.

Open in new tab

When a link opens in a new tab, append a 12×12px hb-link__icon to communicate that intent. Use it only when the behavior genuinely differs — not on every external link.

Best practices

Do

Use descriptive labels that make sense on their own.

Use Default in most contexts; Subtle when it competes with key content.

Use Reverse only on dark or colored backgrounds.

Use links for low-hierarchy actions (e.g. "Forgot your password?").

Don't

Use links for primary or high-importance actions — use buttons.

Use generic text like "click here" or "read more".

Mix variants within the same component without a clear reason.

Add icons unless they communicate a concrete action.
