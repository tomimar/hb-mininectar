SearchInput

SearchInput lets users quickly find content within the current context by typing keywords or phrases. It provides a familiar search interaction across the platform and enables fast access to information in dense interfaces such as tables, lists, and navigation areas.

Example

Compose hb-search with a leading search icon, an hb-search__input, and an optional hb-search__clear button that only appears while the field has a value.

<div class="hb-search">
  <svg class="hb-search__icon" viewBox="0 0 24 24"> … </svg>
  <input class="hb-search__input" type="text" placeholder="Search cases">
  <button class="hb-search__clear" type="button" aria-label="Clear search"> … </button>
</div>

Sizes

Two sizes are available. Large is the default for page-level and primary search. Small is for table toolbars, compact filters and dense layouts.

Size Class Height Use for
— 40px Default. Page-level, table and primary search
hb-search--sm 32px Table toolbars, compact filters, dense layouts

States

States are handled automatically via CSS — hover and focus use the wrapper, disabled uses the input's disabled attribute.

Empty Placeholder text in --ui-disabled, border --ui-border-secondary.
Filled Value in --ui-text, clear (×) button appears.
Focus / Active Border --ui-interaction + 2px --ui-interaction-soft ring (try clicking it).
Disabled Background --ui-bg-tertiary; add disabled to the input.

Anatomy

ElementDescription
1
 Search icon (leading) 20×20px. Indicates that the field is used for searching.
2
 Placeholder / value Inter Regular, 14px. Placeholder describes what users can search (e.g. "Search cases").
3
 Clear action (×) 20×20px. Resets the query. Only appears while the field contains text.

Unlike Input, SearchInput does not include labels or helper text — the placeholder acts as the primary guidance.

Best practices

Do

Use clear, descriptive placeholders (e.g. "Search alerts", "Search entities").

Show results as the user types when possible.

Place the search input close to the content it affects.

Provide a clear action to reset the query.

Don't

Use SearchInput as a replacement for form inputs.

Add labels or helper text — the placeholder provides the guidance.

Use it for validated, required or stored data (dates, numbers, currency).

Overload the field with multiple icons or actions.
