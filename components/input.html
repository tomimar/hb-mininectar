Components

Input

A single-line text input captures short free-form values such as names, emails, or IDs. It shares the common field wrapper, label, and help-text structure so it behaves consistently with every other control. Clear labels and predictable states reduce errors and make forms faster to complete.

Field anatomy

Every control is wrapped in hb-field, which stacks four parts: a hb-field__label (with an optional hb-field__required asterisk), the control itself, and a hb-field__help hint. On error, swap help text for hb-field__error.

As it appears on official documents.

<div class="hb-field">
  <label class="hb-field__label">Full name <span class="hb-field__required">*</span></label>
  <input class="hb-input" type="text" placeholder="Enter your full name">
  <p class="hb-field__help">As it appears on official documents.</p>
</div>

Variants

Single-line text input. Modifiers: hb-input--sm for dense layouts and hb-input--error for invalid values. Use the native disabled attribute for read-only views.

Best practices

Do

We'll send confirmations here.

Always pair a control with a visible label, and mark required fields.

Amount must be greater than zero.

Show errors directly below the field, with help text for guidance.

Don't

Don't use the placeholder as the label — it disappears once typing starts.

Don't leave required fields unmarked — users can't tell what's mandatory.
