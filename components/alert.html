Components

Alert

Alerts communicate important feedback messages. They appear at the top of the page (below the navbar) to display system-wide status, warnings, errors or confirmations. Alerts are non-blocking — they inform without interrupting the user's workflow.

Example

An alert is an icon + message inside hb-alert with a type modifier. The message, an optional inline link and an optional dismiss button.

Scheduled maintenance on Sunday from 2am to 4am. Expect brief downtime. See our blog

<div class="hb-alert hb-alert--info">
  <svg class="hb-alert__icon" …></svg>
  <p class="hb-alert__content">Message <a class="hb-alert__link">See more</a></p>
  <button class="hb-alert__dismiss">…</button>
</div>

Types

Four variants, each with its own color and icon. Use the one that matches the message's intent.

InfoNeutral, informational. No action required.

Scheduled maintenance on Sunday from 2am to 4am.

SuccessConfirms a completed action. Pair with auto-dismiss.

Your changes have been saved successfully.

WarningPotential problem needing attention. Recommended but not blocking.

Your session will expire in 5 minutes. Please save your changes.

ErrorA failure or blocking problem. Never auto-dismiss.

Your request could not be completed. Please try again later.

Anatomy

ElementNotes
Icon20×20px, variant-specific. Essential for accessibility — never remove it.
Message14px medium. Concise and actionable (1–2 lines).
Background + borderSoft fill with a matching solid border per type.
Action link (optional)Inline underlined link inside the message.
Dismiss button (optional)20×20px × close icon, top-aligned.

Best practices

Do

Use the correct variant for the message type.

Keep messages concise and actionable (1–2 lines).

Align the icon to the top when text wraps.

Show a maximum of one alert at a time.

Don't

Auto-dismiss error or warning alerts.

Use alerts for field-level validation — use the Input error state.

Use the warning variant for errors or vice versa.

Remove the icon or use alerts as permanent UI content.
