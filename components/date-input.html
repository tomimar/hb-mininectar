Date input

A date field captures a single date. It pairs a text input with a calendar icon so users can recognize the field's purpose at a glance. This is the static text field; for the full interactive calendar (DatePicker) see the note below.

Example

Wrap the control in hb-date-input and append a calendar icon using hb-date-input__icon. This is the static text field.

<div class="hb-date-input" style="position: relative;">
  <input type="text" class="hb-input" placeholder="MM/DD/YYYY"
    style="padding-right: 40px;">
  <svg class="hb-date-input__icon" viewBox="0 0 24 24"> … </svg>
</div>

DatePicker note

The example above is the static text field only. For the full interactive calendar (DatePicker) — which opens a month grid for point-and-click date selection — Alpine.js is required. See the working implementation in rfi-phase1/rfi.html (copy the hbDatepicker(modelKey) function from the end of its script); there's no need to replicate the calendar here.

Best practices

Do

Use an MM/DD/YYYY format hint in the placeholder so the expected format is clear.

Provide a date picker (DatePicker) for selection so users don't have to type dates by hand.

Don't

Don't rely on free text alone for dates — without a format hint or picker, input is error-prone.
