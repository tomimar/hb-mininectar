Components

Date input

A date field captures a single date. It pairs a text input with a calendar icon and an interactive picker, so users can either type a date or select it visually. Values are always formatted as MM/DD/YYYY.

Example

Add data-hb-datepicker to a hb-date-input wrapper and include datepicker.js. The field works with no dependencies: click to open the calendar, or type a date — slashes are inserted automatically. Try it below.

<div class="hb-date-input" data-hb-datepicker style="position: relative;">
  <input type="text" class="hb-input" placeholder="MM/DD/YYYY"
    style="padding-right: 40px;">
  <svg class="hb-date-input__icon" viewBox="0 0 24 24"> … </svg>
</div>

<script src="https://tomimar.github.io/hb-mininectar/datepicker.js"></script>

Interactive calendar

The calendar opens below the field on click or focus. It supports month navigation with the arrows, a year view (click the month label), and a Today shortcut. Selecting a day fills the field and closes the picker. No framework required — datepicker.js is plain JavaScript.

Best practices

Do

Use an MM/DD/YYYY format hint in the placeholder so the expected format is clear.

Provide a date picker (DatePicker) for selection so users don't have to type dates by hand.

Don't

Don't rely on free text alone for dates — without a format hint or picker, input is error-prone.
