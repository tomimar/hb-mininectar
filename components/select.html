Components

Select

A wrapper around the native <select> that lets users pick a single value from a predefined list. The wrapper draws a consistent border and custom chevron so the control matches the rest of the field system across browsers.

Example

Wrap a native <select> in hb-select. The wrapper draws the custom chevron and border so the control matches the rest of the field system across browsers.

<div class="hb-select">
  <select>
    <option value="">Select an option</option>
    <option>Open</option>
  </select>
</div>

Multi select

Use hb-multiselect when users can pick several options. Selected values appear as removable tags inside the field, and the dropdown lists options with checkboxes. Open / type-to-filter / toggle / remove behaviour is wired with Alpine.js in the prototype; the classes below are the markup and styling contract. Add hb-multiselect--sm for the 32px size.

Best practices

Do

Wrap the native <select> in hb-select and include a placeholder option.

Order options logically (alphabetical, by frequency, or by natural sequence).

Don't

Don't use it for multi-select — use the Popup select instead.

Don't use it for free text — use an hb-input when values aren't predefined.
