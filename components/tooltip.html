Components

Tooltip

A Tooltip displays a short contextual label that appears when a user hovers over or focuses an element. It is non-interactive — it only delivers information, never contains actions or clickable elements.

Example

Wrap a trigger in hb-tooltip and add an hb-tooltip__content bubble. It shows on hover or keyboard focus. Hover the button below.

More information about this action 
<span class="hb-tooltip">
  <button class="hb-fab hb-fab--secondary hb-fab--icon">…</button>
  <span class="hb-tooltip__content" role="tooltip">More information</span>
</span>

The bubble

The bubble uses --ui-text background, white text, 8px padding, 8px radius, 12px caption type and a max-width of 240px.

Short label A longer tooltip wraps onto multiple lines once it reaches its maximum width of 240 pixels.

Placement

Renders below the trigger by default with an 8px gap. Available placements: top, bottom, left, right (add hb-tooltip__content--top / --left / --right). In production it flips to the opposite side if there isn't enough space.

Behaviour

MomentBehaviour
ShowOn hover or keyboard focus (Tab), after a ~300ms delay to avoid accidental triggers.
HideWhen the cursor leaves, focus is lost, or the user presses Escape.
PositionBelow by default; flips to fit the viewport. 8px gap from the trigger.

Best practices

Do

Keep tooltip text short.

Use sentence case for all tooltip content.

Make tooltips accessible via keyboard, not just mouse hover.

Use for icon-only buttons that lack a visible label.

Don't

Put links, buttons or interactive elements inside a tooltip.

Use tooltips for content the user must read to complete a task.

Use a tooltip for critical information that must always be visible.
