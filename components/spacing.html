Spacing

The spacing scale creates consistent rhythm and alignment across the interface. Use spacing tokens for all padding, margin, and gap values instead of arbitrary pixels — this keeps layouts predictable and easy to maintain.

Usage

Guidance on where each part of the scale fits.

RangeUse for
--spacing-4Tight internal padding — compact controls, icon gaps
--spacing-8 / --spacing-16Most common — padding and gaps inside components
--spacing-24 and upSeparation between sections and content blocks
--spacing-48 and upLayout-level spacing — page padding, major regions

Best practices

Do

Use spacing tokens for all padding, margin and gap values.

Reach for spacing-8 and spacing-16 as your defaults.

Use larger steps to separate sections and layout regions.

Don't

Don't use arbitrary pixel values like 6, 10 or 14.

Don't mix inconsistent spacing within a single component.

Don't hardcode spacing in styles when a token exists.
