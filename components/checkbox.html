Components

Checkbox

Checkboxes let users turn an option on or off, or select any number of items from a list of independent choices. Each checkbox stands alone — selecting one has no effect on the others. The full row acts as a generous click target to keep interactions fast and forgiving.

States

The checkbox is a 20×20px control wrapped in a 40px-tall row that defines the full click area. All states are handled automatically via CSS — no extra classes are needed.

Checkbox row

Wrap each checkbox and its label in a hb-checkbox-row <label>. The row spans the full width and is 40px tall, so clicking anywhere — checkbox or text — toggles the option.

<label class="hb-checkbox-row">
  <input type="checkbox" class="hb-checkbox">
  <span>Option label</span>
</label>

Checkbox group

Use hb-checkbox-group to stack related options under a shared hb-checkbox-group__label. Any combination of options may be selected.

Notify me about 
<div class="hb-checkbox-group">
  <span class="hb-checkbox-group__label">Notify me about</span>
  <label class="hb-checkbox-row"><input type="checkbox" class="hb-checkbox"><span>New comments</span></label>
  <label class="hb-checkbox-row"><input type="checkbox" class="hb-checkbox"><span>Status changes</span></label>
  <label class="hb-checkbox-row"><input type="checkbox" class="hb-checkbox"><span>Mentions</span></label>
</div>

Best practices

Do

Use checkboxes for multiple independent selections where any number can be on.

Keep the full 40px row clickable so the label and box both toggle the option.

Permissions

Group related options under a shared label to give them context.

Don't

Don't use checkboxes for mutually exclusive choices — use a Radio group instead.

Avoid a single checkbox for an on/off setting where a toggle fits better.
