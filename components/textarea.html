Components

Textarea

A multi-line input for longer free-form content such as notes, descriptions, or comments. It shares the common field wrapper, label, and help-text structure with the rest of the field system. Give it a sensible default height so users can see they have room to write.

Example

Multi-line input for longer free-form content such as notes or descriptions. Set rows to a sensible default height.

Up to 500 characters.

<textarea class="hb-textarea" rows="3"></textarea>

Best practices

Do

Set a sensible number of rows so the field signals how much room there is.

Use it for longer, free-form content like descriptions, notes, or comments.

Don't

Don't use a textarea for short single-line values — use an hb-input instead.
