FloatingAction

FloatingAction is a compact, high-emphasis action component designed for quick, contextual interactions. Unlike standard buttons, it is optimized for utility-first scenarios such as quick actions, contextual triggers, and lightweight workflows — it sits on top of content with a pill shape and a drop shadow.

Types

Each type represents a different level of emphasis and should be used intentionally to establish a clear hierarchy.

Primary High emphasis. The most important quick action in a local context. 
<button class="hb-fab hb-fab--primary">Button</button>
Secondary Medium emphasis. Standard contextual actions that stay available without dominating. 
<button class="hb-fab hb-fab--secondary">Button</button>

Sizes

Large (40px) is the default. Small (32px) is for dense or compact environments.

Size Class Height Padding / gap
— 40px 8px / 12px · gap 8px
hb-fab--sm 32px 8px · gap 4px

Icons

Icons are always 20×20px. Place an hb-fab__icon before or after the label, or use hb-fab--icon for a square icon-only button.

<button class="hb-fab hb-fab--primary">
  <svg class="hb-fab__icon" …></svg> Left icon
</button>

<button class="hb-fab hb-fab--secondary hb-fab--icon" aria-label="Route">
  <svg class="hb-fab__icon" …></svg>
</button>

Usage

Do

Use for quick, contextual actions that benefit from strong visibility.

Reserve Primary for the single most important quick action in a context.

Keep labels short and action-oriented.

Don't

Replace standard form/page buttons with FloatingAction.

Stack multiple primaries in the same context.

Use it for destructive actions without confirmation.
