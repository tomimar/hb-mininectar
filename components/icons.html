Foundations

Icons

Icons carry meaning, save space, and speed up recognition. Hummingbird uses one library for all of them — Google's Material Icons — so every screen and prototype draws from the same familiar, searchable set. Instead of pasting SVG markup, you write the icon's name as text and the font renders the glyph.

How we use icons

A few principles keep icons consistent and legible across the product.

One library Always Material Icons. Don't mix in icons from other sets or hand-drawn SVGs — if a concept exists in the catalog, use it.
Two variants Outlined is the default, everywhere. Rounded is reserved for more prominent actions and important menus, where a softer, heavier shape reads better. Don't mix the two within one group of controls.
Meaningful, not decorative Pick icons whose meaning is widely understood (a trash can for delete, a pencil for edit). If an icon needs a caption to be understood, add a text label instead.
Always labelled An icon-only button or link needs an aria-label so screen-reader users know what it does. Never rely on the glyph alone for a critical action.
Token sizes & color Use the size modifiers (16 / 20 / 24px) rather than arbitrary values. Color follows a fixed model: --ui-icon by default, the button's text color inside a button, and the link color inside a link.

Basic usage

The Material Icons fonts are loaded by tokens.css, so no extra <link> is needed in a prototype. Add the hb-icon class to a <span> and set its text to the icon name (in snake_case). The Outlined variant is the default.

Variants

Two styles are loaded, mirroring the variants used in Hummingbird. Use Outlined as the default; reach for Rounded on more prominent actions and important menus, where a softer, weightier shape reads better.

Outlined — default The everyday style. Applied automatically by hb-icon.
home settings calendar_today account_circle notifications 
<span class="hb-icon">settings</span>
Rounded Prominent actions and important menus. Add hb-icon--rounded.
home settings calendar_today account_circle notifications 
<span class="hb-icon hb-icon--rounded">settings</span>

Sizes

Three token-backed sizes cover most needs. The default (20px) suits inline UI; --sm (16px) fits dense controls like small buttons and table rows; --lg (24px) is for prominent, standalone icons.

favorite--sm · 16
favoritedefault · 20
favorite--lg · 24
<span class="hb-icon hb-icon--sm">favorite</span>
<span class="hb-icon">favorite</span>
<span class="hb-icon hb-icon--lg">favorite</span>

Color

An icon's default color is always --ui-icon. Inside a button it inherits the button's text color, and inside a link it inherits the link color — so icons always match the control they sit in. To force a specific color, set color inline with a token.

info Download download error 
<span class="hb-icon">info</span>                            <!-- default: --ui-icon -->
<button class="hb-btn hb-btn--primary"><span class="hb-icon">check</span>Approve</button>
<span class="hb-icon" style="color: var(--ui-status-danger);">error</span>  <!-- override -->

In context

Icons pair naturally with other components. Inside a button or link they inherit that control's text color; an icon-only control always needs an accessible name via aria-label.

Open report open_in_new 
<button class="hb-btn hb-btn--primary hb-btn--lg">
  <span class="hb-icon">add</span>New case
</button>

<button class="hb-btn hb-btn--ghost hb-btn--sm" aria-label="Edit">
  <span class="hb-icon">edit</span>
</button>

Guidance

check Do
Use Material Icons names from the catalog so prototypes share one consistent set.
Give every icon-only control an aria-label describing its action.
Let icons keep their color model: --ui-icon by default, inheriting inside buttons and links.
Reserve the Rounded variant for prominent actions and important menus.
close Don't
Paste raw SVG markup for an icon that already exists in Material Icons.
Mix Outlined and Rounded within the same group of controls.
Hardcode a pixel size or hex color — use the size and color modifiers/tokens.
Rely on an icon alone to convey a critical action without a text or ARIA label.
