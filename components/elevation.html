Foundations

Elevation

Elevation communicates depth through shadow in light mode. It signals that an element floats above the canvas — apply it only when elements overlap other content, such as dropdowns and modals.

Shadow tokens

Two shadow tokens cover the elevation needs of the system. Each is shown on a white surface.

--shadow-overlay
Dropdowns, popovers, sticky bars
--shadow-floating
Modals, floating windows
TokenValueUsage
--shadow-overlay0 2px 6px rgba(0,0,0,0.16)Dropdowns, popovers, sticky bars
--shadow-floating0 8px 24px rgba(0,0,0,0.14)Modals, floating windows

Best practices

Do

Apply shadows only when an element overlaps other content.

Use the layer tokens to keep elevation consistent.

Keep to the two floating levels defined by the system.

Don't

Don't use shadows decoratively on resting elements.

Don't stack multiple shadows on one element.

Don't apply elevation to every card or surface.
