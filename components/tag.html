Components

Tag

Tags are compact labels used to communicate status, category, or metadata. Their color carries meaning, so it should be applied consistently across the platform. Tags help users scan and group information quickly without adding visual noise.

Colors

Each tag uses a soft background with a matching contrast text color. Pick the color by meaning, not decoration — see Usage for semantic mapping.

Grey Green Red Yellow Blue Orange Pink Brown Purple Outlined 
<span class="hb-tag hb-tag--blue">Open</span>
<span class="hb-tag hb-tag--green">Resolved</span>

With remove button

Add hb-tag__remove when a tag represents a removable selection, such as an applied filter or an editable list of values. Always include an aria-label for screen readers.

Open High priority Resolved 
<span class="hb-tag hb-tag--blue">Label
  <button class="hb-tag__remove" aria-label="Remove">×</button>
</span>

Tag group

Wrap multiple tags in hb-tag-group to lay them out in a consistent, wrapping row with even spacing.

Open In review Resolved Submitted Cancelled 
<div class="hb-tag-group">
  <span class="hb-tag hb-tag--blue">Open</span>
  <span class="hb-tag hb-tag--green">Resolved</span>
</div>

Map colors to meaning consistently so users can learn the system once and recognize status at a glance.

Best practices

Do
Open Resolved Cancelled

Use color consistently for status — the same status is always the same color.

Submitted In review

Keep labels short — one or two words that read at a glance.

Don't
G R

Don't rely on color alone to convey meaning — always include a clear text label.

A B C D E F G

Don't use too many colors in one view — it overwhelms and dilutes meaning.
