Components

Radio

Radio buttons let users choose exactly one option from a set of mutually exclusive choices. Selecting one option clears the others in the same group. All options should be visible at once so users can compare them before deciding. The full row acts as the click target.

States

The radio is a 20×20px control wrapped in a 40px-tall row that defines the full click area. All states are handled automatically via CSS — no extra classes are needed.

Radio group (vertical)

Use hb-radio-group to stack options under a shared hb-radio-group__label. Every option in the group must share the same name so only one can be selected at a time.

Radio group (inline)

Add hb-radio-group--inline to lay the options out horizontally. This is the recommended layout for short Yes / No / N/A sets where the options are brief and fit on one line.

Best practices

Do

Use radios for one-from-many choices, with a sensible default pre-selected.

Use the inline layout for short Yes / No / N/A sets to save vertical space.

Show all options at once so users can compare before choosing.

Don't

Don't use radios when more than one option can be selected — use Checkbox instead.

Don't use disabled to hide options — remove unavailable choices instead.
