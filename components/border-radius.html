Foundations

Border radius

Border radius tokens reinforce visual hierarchy and brand character. A small set of consistent values keeps components feeling cohesive — from compact inputs to large surfaces and pill-shaped elements.

Scale

Each token applies a fixed corner radius. Use the smallest value that suits the component.

--border-radius-4 4px Inputs, checkboxes, compact components
--border-radius-8 8px Buttons, cards, dropdowns (default)
--border-radius-16 16px Modals, large surfaces
--border-radius-round 9999px Avatars, pills, circular elements

Best practices

Do

Use radius-8 as the default for buttons, cards and dropdowns.

Use radius-4 for dense or compact UI like inputs.

Use radius-16 for emphasis on modals and large surfaces.

Use round for pills, avatars and circular elements.

Don't

Don't mix different radii within a single component.

Don't use arbitrary radius values outside the token set.

Don't apply round to rectangular content surfaces.
