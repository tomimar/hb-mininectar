Foundations

Colors

The color palette is built on the Nectar tokens. Semantic tokens map raw values to intent — scaffolding for surfaces, foreground for text, interaction for actions, status for feedback, and expressive colors for tags and data visualization. Always reference tokens rather than raw hex values.

Scaffolding

Background and border colors that form the structural surfaces of the interface.

--ui-bg#ffffff
--ui-bg-secondary#f5f5f5
--ui-bg-tertiary#e8e8e8
--ui-bg-overlay#ffffff
--ui-border#d1d1d1
--ui-border-secondary#b8b8b8

Best practices

Do

Use scaffolding tokens for surfaces and borders.

Use foreground tokens for all text and icons.

Use interaction tokens for primary actions, focus and links.

Use status tokens for feedback — danger, success, warning.

Use expressive colors for tags, avatars and charts.

Don't

Don't use expressive colors for core UI elements like buttons or backgrounds.

Don't use raw hex values outside the token set.

Don't repurpose status colors for decoration.
