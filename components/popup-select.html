Popup select

A popup select is a floating panel for choosing one or more options from a predefined list. It is triggered outside of form contexts — toolbar filters, table-row actions, segment pickers — where a full form field would be too heavy. Each option pairs a checkbox with a label, so users can select several values at once.

Overview / Anatomy

The popup select is composed of two regions: a header that names the selection and offers a way to clear it, and a scrollable list of selectable options. It floats above content and is dismissed when the user clicks away or confirms.

Usage

Reach for a popup select when users pick from a known, finite set of values outside of a form. For in-form selection use a Select field instead.

Use whenAvoid when
Selecting multiple values outside a form — toolbar and table filters. The control lives inside a form — use a Select field for consistent layout and validation.
The set of options is predefined and known up front. Users need to enter free text or arbitrary values — use an input.
A lightweight, dismissible panel fits the surface (toolbar, row action). Only one value can ever be chosen and persistent display is needed — consider a Select or Radio group.

Best practices

Do
Status

Order options logically and show counts so users can gauge impact before selecting.

Keep labels short and scannable — one or two words per option.

Don't

Don't pack long descriptions into options. They break the scannable list rhythm.

Don't use a popup select inside a form — use a Select field so it aligns with surrounding inputs.
