Foundations

Typography

Typography establishes hierarchy, rhythm, and readability across every interface. The system uses a single typeface — Inter — and a small, deliberate set of styles. Use the semantic text classes instead of raw font sizes so type stays consistent and easy to maintain.

Type styles

Each style maps to a single class. The first column renders live in the corresponding style so you can compare them directly.

Style Class Specs

Usage

Pick a style by the role the text plays, not by how it looks. Each style has a clear purpose in the hierarchy.

Style Use for
Heading Page and panel titles — the most prominent text in a view.
Heading small Section titles, card headers, and field group labels.
Body Default style for paragraphs, table cells, and most content.
Body bold Emphasis within body text, inline labels, and key values.
Caption Secondary metadata: timestamps, helper text, counts.
Caption bold Small emphasized labels, table headers, and tags.
All caps Eyebrow labels and section dividers that frame content.
